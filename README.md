Requires usage of Platform Io 
You also need the Arduino nano 33 BLE micro controller to use this specific code and config files
But a lot can be done to cause it to run with ESP32 over Wifi for controls. 
Building the app, i used Sliders for increasing and decreasing motor speed.  The animations Function simply animates a slider on the DIY app .  see https://dashio.io/guide-arduino-nano33ble/
